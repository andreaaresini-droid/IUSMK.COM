C’è ancora un problema nel recupero password: il frontend mostra il messaggio di successo, ma nessuna email viene inviata.

Devi controllare e correggere SOLO il sistema email/reset password, senza toccare Stripe, corsi, notifiche admin o altre funzioni.

OBIETTIVO
Voglio che il recupero password invii davvero l’email tramite Resend, e che i log mostrino chiaramente ogni passaggio.

CONTROLLI E MODIFICHE OBBLIGATORIE

1. Verifica che il progetto stia usando davvero Resend e NON SMTP/Nodemailer.
2. Cerca nel codice del forgot-password se il flusso chiama realmente una funzione sendEmail().
3. Verifica che la funzione sendEmail usi davvero:
   - process.env.RESEND_API_KEY
   - process.env.EMAIL_FROM
4. Aggiungi log chiari nel backend, in questo ordine:
   - [FORGOT_PASSWORD] richiesta ricevuta
   - [FORGOT_PASSWORD] utente trovato / utente non trovato
   - [FORGOT_PASSWORD] token creato
   - [FORGOT_PASSWORD] reset link creato
   - [FORGOT_PASSWORD] tentativo invio email con Resend
   - [FORGOT_PASSWORD] risposta Resend successo
   - [FORGOT_PASSWORD] errore Resend completo
5. Se RESEND_API_KEY manca, stampa nei log:
   [EMAIL_ERROR] RESEND_API_KEY mancante
6. Se EMAIL_FROM manca, stampa nei log:
   [EMAIL_ERROR] EMAIL_FROM mancante
7. Se il backend oggi risponde sempre con successo anche quando l’email fallisce, mantieni pure il messaggio neutro al frontend ma registra nei log l’errore reale completo.
8. Verifica che APP_URL venga usato correttamente per costruire il reset link.
9. Verifica che il link venga realmente inserito nel corpo email.
10. Fai in modo che il server NON vada in crash se Resend fallisce.
11. Per test, aggiungi temporaneamente un endpoint protetto o una utility semplice che invii una email di prova via Resend, così posso verificare che il provider funzioni indipendentemente dal reset password.
12. Alla fine scrivimi nei log chiaramente uno di questi risultati:
   - [EMAIL_OK] email inviata correttamente
   - [EMAIL_FAIL] invio fallito con motivo preciso

IMPLEMENTAZIONE RESEND
Usa la libreria ufficiale resend.
La funzione deve essere qualcosa di questo tipo:

import { Resend } from 'resend';

const resend = new Resend(process.env.RESEND_API_KEY);

export async function sendEmail(to, subject, html) {
  console.log('[EMAIL] sendEmail called', { to, subject });

  if (!process.env.RESEND_API_KEY) {
    console.error('[EMAIL_ERROR] RESEND_API_KEY mancante');
    return { ok: false, error: 'missing_api_key' };
  }

  if (!process.env.EMAIL_FROM) {
    console.error('[EMAIL_ERROR] EMAIL_FROM mancante');
    return { ok: false, error: 'missing_email_from' };
  }

  try {
    const result = await resend.emails.send({
      from: process.env.EMAIL_FROM,
      to,
      subject,
      html,
    });

    console.log('[EMAIL_OK] Resend response:', result);
    return { ok: true, result };
  } catch (error) {
    console.error('[EMAIL_FAIL] Resend error:', error);
    return { ok: false, error };
  }
}
