CONTROLLI OBBLIGATORI

1) CONTROLLA DOVE VENGONO SALVATE LE VOCI
Verifica che le nuove voci siano state salvate davvero nella stessa tabella/collezione usata dalla pagina “Knowledge Base AI”.
Controlla se per errore:
- vengono salvate in una tabella diversa
- vengono salvate in un ambiente diverso
- vengono salvate in memoria temporanea
- vengono salvate in un JSON/mock e non nel database reale
- vengono salvate in una collection diversa da quella letta dalla dashboard

2) CONTROLLA LA QUERY DELLA PAGINA KNOWLEDGE BASE AI
Verifica la query usata dalla schermata admin.
La lista deve leggere TUTTE le voci con:
- isPublished = true
- isActive = true
oppure, se la schermata mostra “Tutte”, deve leggere tutte le voci senza nasconderle.

Controlla che la query non abbia per errore:
- limit 1
- pagination rotta
- offset errato
- order/filter sbagliati
- filtro categoria che blocca i risultati
- filtro testuale iniziale non vuoto
- filtro solo “manual_entry”
- filtro su createdBy o sourceType che esclude le nuove voci

3) CONTROLLA IL FRONTEND DELLA LISTA
Verifica se i dati arrivano davvero al frontend ma vengono mostrati male.
Controlla:
- rendering della lista
- map sui record
- key duplicate
- slicing accidentale
- stato React/Vue non aggiornato
- cache non invalidata
- fetch che usa dati vecchi
- revalidation non eseguita
- useEffect / loader / state che sovrascrivono i record

4) CONTROLLA I FILTRI DELLA PAGINA
Nella schermata vedo:
- Cerca...

Verifica che i filtri non stiano bloccando i risultati appena creati.

Se necessario, correggi i filtri in modo che al primo caricamento:
- non venga applicato nessun filtro nascosto
