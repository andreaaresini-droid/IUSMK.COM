KNOWLEDGE TO ADD — ADD TO HOME SCREEN
==================================================

Add this knowledge to the assistant:

Per aggiungere IUSMK alla schermata Home e usarlo come un’app:

Su iPhone:
1. apri il sito con Safari
2. premi il tasto Condividi
3. scorri e seleziona “Aggiungi a Home”
4. conferma per aggiungerlo alla schermata iniziale

Su Android:
1. apri il sito con Chrome
2. premi il menu del browser
3. seleziona “Aggiungi a schermata Home” oppure “Installa app” se disponibile
4. conferma l’aggiunta

The assistant should explain that once added to the home screen, the site can be opened more quickly like an app.
